## 데이터 흐름

```
사용자 요청
    ↓
┌────────────────────────────────────┐
│ 1. analyzeComplexity()             │
│    - 복잡도 점수 계산 (1-10)        │
│    - 서브태스크 식별               │
│    - 병렬 에이전트 수 결정          │
└────────────────────────────────────┘
    ↓
┌────────────────────────────────────┐
│ 2. analyzeAndRoute()               │
│    - 트리거 키워드 매칭            │
│    - 적합한 에이전트 선택          │
│    - LLM 모델 할당                 │
└────────────────────────────────────┘
    ↓
┌────────────────────────────────────┐
│ 3. executeParallel()               │
│    - 배치로 나누어 실행            │
│    - 이벤트 발생 (started/done)    │
│    - 결과 수집                     │
└────────────────────────────────────┘
    ↓
┌────────────────────────────────────┐
│ 4. aggregateResults()              │
│    - 성공/실패 집계                │
│    - 최종 결과 보고                │
└────────────────────────────────────┘
```

## 핵심 컴포넌트

### 1. BmadOrchestrator

메인 오케스트레이터 - 모든 에이전트를 조율

| 메서드 | 설명 |
|--------|------|
| `analyzeComplexity()` | 작업 복잡도 분석 |
| `analyzeAndRoute()` | 에이전트 할당 |
| `executeParallel()` | 병렬 실행 |
| `aggregateResults()` | 결과 집계 |
| `on()` | 이벤트 리스너 등록 |

### 2. LLMRouter

에이전트별 최적 모델 선택

| 메서드 | 설명 |
|--------|------|
| `selectModelForAgent()` | 에이전트용 모델 선택 |
| `selectOptimalModel()` | 요구사항 기반 선택 |
| `trackUsage()` | 사용량 추적 |

### 3. AccountManager (수정됨)

무료 계정 우선 정책 적용

| 메서드 | 설명 |
|--------|------|
| `getCurrentOrNextForFamily()` | 무료 우선 계정 선택 |
| `setConfig()` | 정책 설정 |
| `getUsageStats()` | 사용 통계 |

## 이벤트

| 이벤트 | 발생 시점 |
|--------|----------|
| `task:created` | 태스크 생성 |
| `task:started` | 실행 시작 |
| `task:completed` | 완료 |
| `agent:started` | 에이전트 시작 |
| `agent:completed` | 에이전트 완료 |
| `agent:error` | 에이전트 에러 |
| `account:switched` | 계정 전환 |
| `account:rate_limited` | Rate Limit |
